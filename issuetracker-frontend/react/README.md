# Issue Tracker - Frontend 🚀

Това е потребителският интерфейс на нашия проект за управление на задачи (Issue Tracker), изграден с React.

## 🛠️ Как да стартирате проекта локално

1. Уверете се, че имате инсталиран Node.js.
2. Отворете терминала в папката на проекта и инсталирайте нужните пакети:
   npm install
3. Стартирайте приложението в режим на разработка:
   npm run dev
